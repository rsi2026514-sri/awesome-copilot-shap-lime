# Datasets

This section lists publicly available datasets that can be used to experiment with machine-learning models and compare explainability methods such as SHAP and LIME.

## 1. UCI Adult Dataset

* **Source:** UCI Machine Learning Repository
* **Task:** Classification
* **Description:** The Adult dataset is used to predict whether a person's annual income exceeds $50,000 based on census-related attributes.
* **Features:** The dataset contains demographic and employment-related features.
* **Why it is relevant:** It is a useful tabular classification dataset for generating local and global explanations using SHAP and LIME.
* **Possible experiment:** Train a decision-tree, random-forest, or other classifier and compare the feature importance produced by SHAP and LIME for the same predictions.
* **Official source:** https://archive.ics.uci.edu/dataset/2/adult

---

## 2. UCI Bank Marketing Dataset

* **Source:** UCI Machine Learning Repository
* **Task:** Classification
* **Description:** The Bank Marketing dataset contains information from direct marketing campaigns conducted by a Portuguese banking institution. The classification task is to predict whether a client will subscribe to a term deposit.
* **Instances:** Approximately 45,000
* **Features:** 17
* **Why it is relevant:** It provides a realistic tabular classification problem with multiple numerical and categorical variables, making it suitable for comparing local explanations from LIME and SHAP.
* **Possible experiment:** Train a classification model, select individual predictions, and compare which features LIME and SHAP identify as the main contributors.
* **Official source:** https://archive.ics.uci.edu/dataset/222/bank+marketing

---

## 3. UCI Breast Cancer Wisconsin (Diagnostic) Dataset

* **Source:** UCI Machine Learning Repository
* **Task:** Classification
* **Description:** This dataset contains features computed from digitized images of fine-needle aspirate (FNA) of breast masses. The task is to classify tumors as malignant or benign.
* **Why it is relevant:** It is a well-known binary classification dataset that can be used to study feature-level explanations of model predictions.
* **Possible experiment:** Train a Random Forest, Support Vector Machine, or another classifier and compare SHAP and LIME explanations for benign and malignant predictions.
* **Official source:** https://archive.ics.uci.edu/dataset/17/breast+cancer+wisconsin+diagnostic

---

## How These Datasets Can Be Used

The datasets can support a common experimental workflow:

1. Load and preprocess the dataset.
2. Split the data into training and testing sets.
3. Train a machine-learning model.
4. Select individual test samples for explanation.
5. Generate explanations using **LIME**.
6. Generate explanations using **SHAP**.
7. Compare the features identified by both methods.
8. Evaluate differences in feature importance, explanation consistency, and interpretability.
9. Record the results for comparison with explanations generated by an AI Copilot.

### Dataset Selection Rationale

The three datasets provide different tabular classification problems. The Adult and Bank Marketing datasets contain demographic, social, and financial attributes, while the Breast Cancer Wisconsin dataset provides a medical classification problem. UCI lists Adult, Bank Marketing, and Breast Cancer Wisconsin among its established datasets.

These datasets can therefore provide varied test cases for evaluating whether different explainability approaches produce consistent and understandable explanations.

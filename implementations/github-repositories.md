# GitHub Implementations

This section contains GitHub repositories with practical implementations of explainable AI methods, particularly SHAP and LIME. These repositories can be used as references for implementing and comparing different explanation techniques.

## 1. Cloudera — Explainability with LIME and SHAP

* **Repository:** `cloudera/CML_AMP_Explainability_LIME_SHAP`
* **Purpose:** Demonstrates how to explain machine-learning models using LIME and SHAP.
* **Methods:** LIME, SHAP KernelExplainer, SHAP TreeExplainer
* **Content:** Includes practical examples, notebooks, model interpretation techniques, and discussion of limitations of LIME and SHAP.
* **Relevance:** Highly relevant to this project because it directly demonstrates and compares LIME and SHAP explanations.
* **GitHub:** https://github.com/cloudera/CML_AMP_Explainability_LIME_SHAP

The repository specifically demonstrates local explanations generated by both LIME and SHAP and discusses when each method can be useful.

---

## 2. ArturoSbr — LIME and SHAP Examples

* **Repository:** `ArturoSbr/lime-shap`
* **Purpose:** Provides examples for interpreting machine-learning models using LIME and SHAP.
* **Content:** Includes a Jupyter notebook demonstrating both explainability approaches.
* **Methods:** LIME and SHAP
* **Relevance:** Useful as a simple implementation reference for understanding how the two methods can be applied to the same AI model.
* **GitHub:** https://github.com/ArturoSbr/lime-shap

The repository contains a notebook specifically designed to demonstrate LIME and SHAP methodologies for explaining AI models.

---

## 3. Krishang118 — XAI SHAP LIME

* **Repository:** `krishang118/XAI-SHAP-LIME`
* **Purpose:** Demonstrates SHAP and LIME explainability techniques using an Artificial Neural Network trained on the Iris dataset.
* **Dataset:** Iris dataset
* **Model:** Artificial Neural Network
* **Methods:** SHAP and LIME
* **Content:** Includes individual prediction analysis, SHAP visualizations, LIME explanations, stability analysis, and side-by-side comparison.
* **Relevance:** Particularly useful because it explicitly includes a LIME-versus-SHAP comparison.
* **GitHub:** https://github.com/krishang118/XAI-SHAP-LIME

The repository reports separate SHAP and LIME analyses and includes a comparison of feature importance and LIME stability.

---

## 4. van der Schaar Lab — Interpretability

* **Repository:** `vanderschaarlab/Interpretability`
* **Purpose:** Provides resources and implementations for machine-learning interpretability methods.
* **Methods:** SHAP, LIME, Integrated Gradients, SimplEx, Dynamask, and other interpretability approaches.
* **Content:** Includes implementations, notebooks, method-selection resources, and examples.
* **Relevance:** Useful for comparing multiple explainability techniques and understanding how SHAP and LIME fit within the wider XAI landscape.
* **GitHub:** https://github.com/vanderschaarlab/Interpretability

The repository provides a common interface for several interpretability methods and includes SHAP and LIME resources.

---

## 5. LIME — Official Implementation

* **Repository:** `marcotcr/lime`
* **Purpose:** Official implementation of Local Interpretable Model-Agnostic Explanations (LIME).
* **Supported data:** Tabular data, text, and images.
* **Content:** Contains the LIME implementation, examples, tutorials, documentation, and notebooks.
* **Relevance:** Provides the original implementation and practical examples of the LIME explainability method.
* **GitHub:** https://github.com/marcotcr/lime

The repository supports explanations for individual predictions involving tabular, text, and image data and includes practical tutorials.

## How These Implementations Can Be Used

These repositories provide practical starting points for the experimental component of this project.

A possible workflow is:

1. Select a dataset from `datasets/datasets.md`.
2. Train a machine-learning model.
3. Generate an explanation using SHAP.
4. Generate an explanation using LIME.
5. Compare the important features identified by both methods.
6. Record differences in feature importance and explanation behavior.
7. Compare these results with explanations generated by an AI Copilot.
8. Analyze whether the AI Copilot explanation agrees with the manually generated SHAP/LIME explanations.

### Implementation Selection

The Cloudera repository and the `krishang118/XAI-SHAP-LIME` repository are especially relevant because they directly demonstrate LIME and SHAP together. The van der Schaar Lab repository is useful for broader comparison with other interpretability techniques.
